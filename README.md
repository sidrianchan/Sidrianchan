- **[MSc dissertation, *No Single Metric Is Enough*](https://github.com/sidrianchan/gnn-explanation-metrics)**: GNN explanations are judged by four standard metrics. I held the model, explainer and metric definitions fixed, changed only the data, and built synthetic graphs that make three of the four give a misleading verdict on command. GNNExplainer scored below a random baseline on ground-truth accuracy yet beat it on fidelity; an explanation that ignores the model scored over 4× higher on stability. Fidelity resisted four construction attempts, which I report rather than hide.
- **[BSc dissertation, Domain-Specific Sentiment Analysis](https://github.com/sidrianchan/fyp-sentiment-analysis)**: TF-IDF + linear SVM, a Bi-LSTM with attention, and fine-tuned BERT on Amazon Fine-Food Reviews. BERT reached macro-F1 0.9565 against a 0.95 target, with negative-class recall 4.64% above the baseline; SHAP analysis for interpretability.
- **[nlp-tweet-sentiment-classification](https://github.com/sidrianchan/nlp-tweet-sentiment-classification)**: an end-to-end text classification pipeline (macro-F1 0.894 under 10-fold cross-validation).
